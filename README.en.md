# crud-posts

🇺🇸 English | 🇧🇷 [Português](README.md)

> A posts CRUD app consuming the JSONPlaceholder API, with React + Material UI.

## Overview

An educational **CRUD** app (create, read, update, delete) for posts, consuming the public [JSONPlaceholder](https://jsonplaceholder.typicode.com/) API. It demonstrates REST API integration via Axios, routing, and Material UI components.

## Features

- List posts (GET) and filter by ID
- Create post (POST) via a form
- Edit post (PUT)
- Delete post (DELETE)
- Loading states and error handling

## Stack

React 18 · React Router DOM 6 · Axios · MUI (Material UI) 5 · Create React App.

## Running

```bash
npm install
npm start          # http://localhost:3000
```

> Note: JSONPlaceholder is a mock API — writes (POST/PUT/DELETE) return success but do not persist on the server.

## Project status

Functional and complete for educational purposes.
