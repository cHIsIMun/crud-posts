# crud-posts

🇧🇷 Português | 🇺🇸 [English](README.en.md)

> Aplicação CRUD de posts consumindo a API JSONPlaceholder, com React + Material UI.

## Visão geral

App educacional de **CRUD** (criar, ler, atualizar, deletar) de posts, consumindo a API pública [JSONPlaceholder](https://jsonplaceholder.typicode.com/). Demonstra integração com API REST via Axios, roteamento e componentes do Material UI.

## Funcionalidades

- Listar posts (GET) e filtrar por ID
- Criar post (POST) via formulário
- Editar post (PUT)
- Deletar post (DELETE)
- Estados de carregamento e tratamento de erro

## Stack

React 18 · React Router DOM 6 · Axios · MUI (Material UI) 5 · Create React App.

## Como executar

```bash
npm install
npm start          # http://localhost:3000
```

> Observação: a JSONPlaceholder é uma API de simulação — as escritas (POST/PUT/DELETE) retornam sucesso mas não persistem no servidor.

## Estado do projeto

Funcional e completo para fins educacionais.
